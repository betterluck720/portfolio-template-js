# Portfolio Templates

A collection of responsive personal portfolio website templates built with JavaScript, React, and Next.js.

## Templates

| Template | Technology | Location |
|---|---|---|
| Tunis | React 17 | [`template1`](./template1) |
| Bostami | React / Next.js | [`template2`](./template2) |

## Repository Structure

```text
portfolio-template-js/
├── template1/
│   ├── public/
│   └── src/
├── template2/
│   ├── nextjs-version/
│   └── react-version/
└── README.md
```

## Template 1: Tunis

The Tunis template is a React personal portfolio featuring reusable components, routing, Bootstrap styling, animations, and portfolio sections.

### Technologies

- React 17
- React Router
- Bootstrap 5
- React Hook Form
- React Modal
- React Slick
- AOS animations
- Sass
- React Scripts

### Run Template 1

**Prerequisites:** Node.js and npm

```bash
cd template1
npm install
npm start
```

Open `http://localhost:3000` in your browser.

### Build for Production

```bash
npm run build
```

The optimized production files will be generated in `template1/build`.

## Template 2: Bostami

Template 2 includes both React and Next.js implementations in separate directories:

```text
template2/
├── react-version/
└── nextjs-version/
```

Each implementation contains its own setup instructions. Use the README or package configuration inside the selected version for framework-specific commands.

## Technology Composition

- JavaScript: 91.7%
- CSS: 7.4%
- HTML: 0.9%

## Customization

Personalize the templates by updating:

- Profile and contact information
- Projects and portfolio entries
- Images and assets
- Colors and theme settings
- Resume, skills, and experience content
- Routes and navigation labels
